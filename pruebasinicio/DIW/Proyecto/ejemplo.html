Mockup y especificaciones

Este documento recoge las partes de la interfaz, sus características y restricciones de datos.

Componente: Campo Email

Tipo: input[type=email] — Requerido: sí

Validación: HTML5 (type="email") y patrón adicional si se desea.

Comportamiento: foco con outline visible; mensaje de error si inválido.

Componente: DNI (opcional)

Tipo: input[type=text]

Patrón: \d{8}[A-Za-z] (ejemplo 12345678A)

Requerido: opcional. Mostrar ayuda en caso de formato incorrecto.

Botón

Estilos: botón principal (.btn) con color primario, border-radius 10px, padding 10x14.

Estados: hover (oscurecer), disabled (opacidad 60%).

Enlaces y navegación

Hipervínculos: navegación entre páginas (index, login, departments, product, search, cart). En el mockup se implementan para navegación local.

Responsive

Se usan media queries en 900px y 600px para adaptar layout de grid y ocultar la navegación principal en móviles.
